# yt-download-guide
Beginner-friendly Windows guide for using yt-dlp and FFmpeg to download media you are authorized to save.

## ⚠️ Usage Notice
This guide is intended for downloading media that you own, media
you have permission to download, or media that applicable law permits
you to download.

Respect copyright, content creators' rights, and the terms of the
services you use.

This project is an independent tutorial and is not affiliated with
YouTube, Google, yt-dlp, FFmpeg, or Gyan.dev.

# yt-download-guide

A beginner-friendly Windows guide for setting up **yt-dlp** and **FFmpeg** to download media you are authorized to save.

## What this guide covers

This guide shows you how to:

- Download and set up yt-dlp on Windows
- Install FFmpeg
- Verify the installation
- Download a video using PowerShell
- Find the downloaded file on your computer

👉 See the full guide here: [INSTRUCTIONS.md](INSTRUCTIONS.md)
